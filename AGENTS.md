# CNERD Blog Engine

This is a standalone Node/SQLite application. Read README.md and docs/ARCHITECTURE.md for installation and ownership boundaries. No other website checkout is required.

Run all runtime checks with an isolated DATA_DIR. One installation has one brand and one database/media directory. Preserve version-2 documents, published snapshots, revisions, private training, integration ownership and idempotency, and saved-audio fingerprints.

Reuse the React/Tiptap editor and canonical content contract. When parallel agents are authorized, shared schemas, database/bootstrap, server routes and package dependencies have one integration owner. A repository change or push does not authorize deployment, social publication, paid inference, credential rotation, or indexing requests.

Keep installation secrets, runtime data, reference recordings, backups, build outputs and machine-specific evidence out of Git. Never commit a node_modules symlink. Run npm test and npm run build for consequential runtime changes; use rendered checks for UI work. Native-browser tests may need local server access and an installed Chrome/Chromium browser.
